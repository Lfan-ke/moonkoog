moonkoog

0.2.0 · Apache-2.0

A MoonBit port of JetBrains Koog — a type-safe agent-orchestration framework.

A prompt/message model, an LLM-client contract, a tool registry with an explicit JSON-schema descriptor, and an AIAgent that drives the tool-calling loop. Part of the moon-heke full-stack suite.

Read the README GitHub Examples

The core loop

let agent = @agent.AIAgent::new(
  client,
  model=@llm.deepseek_v4_flash,
  tool_registry=@tools.ToolRegistry::new().add(Add::{}),
)
let answer = agent.run("what is 2 + 3?")
